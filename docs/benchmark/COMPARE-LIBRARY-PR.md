## What changed
- **`SAM.Analytical.Benchmark.Compare`** is now a net8.0 **class library**, built to `build\SAM.Analytical.Benchmark.Compare.dll`.
  - It holds the existing `Classes/`, `Query/` and `Modify/` sources, unmoved and with no logic change.
  - Its only dependency is still the schema project.
  - `Modify.Format` (`internal`) became `public`, so consumers show exactly the strings the reports contain: number, percent, unit, band, gate, availability, match kind and metric note. No other source changed.
- **`SAM.Analytical.Benchmark.Compare.Cli`** (new) holds only `Program.cs`, moved unchanged.
  - It builds `benchmark-compare` into `build\`, as before.
  - Usage, options, outputs and exit codes are unchanged.
- **`ExtractionRegressionTests`** use the goldens in `Fixtures/Regression/{fixtures,scenario,weather-mismatch}/`:
  - The goldens were generated by the **pre-extraction** CLI at base `c9a7f19`. They hold both input documents, `comparison.md/.csv/comparison-summary.json`, and `cli-<never|warn|fail>.txt` with the exit code and console output.
  - The library route (`Read` + `Query.Compare` + `Modify.WriteReports`) and the wrapper CLI must both reproduce them byte for byte.
  - The `fixtures` case is equal to the committed `Fixtures/comparison.*`.
- **`SAM.Analytical.Benchmark.Compare.ApiTests`** (new) is outside `InternalsVisibleTo`, so it compiles only against the public surface SAM_UI consumes. It exercises:
  - compare;
  - statuses and counts;
  - provenance mismatches;
  - every `MetricComparison` member, rendered with `Format`;
  - spaces, diagnostics and reconciliation;
  - `WriteReports`.
- **Per-engine metric enumeration** (`Query/MetricValues.cs`, added for SAM_UI's unified Run Simulation partial-completion display):
  - `Query.ModelMetricValues(BenchmarkModelResult?)` and `Query.SpaceMetricValues(BenchmarkSpaceResult?)` return one engine's metrics as ordered `(key, MetricValue?)` pairs. Keys and order match the comparator's rows, and an unreported metric has a `null` value: nothing is substituted.
  - `CompareModel`/`CompareSpaceMetrics` now build their rows from these lists, so the key list exists once. The regression goldens are unchanged.
- **`.github/workflows/build.yml`:** the engine-reference check now covers the library and the CLI, and the API tests run after the comparator tests.

Public API (supported contract):
- `Query.Compare`, `Query.IsInformationalForNumericalGate`, `Query.ModelMetricValues`, `Query.SpaceMetricValues`;
- `Modify.WriteReports`, `WriteMarkdown`, `WriteCsv`, `WriteSummaryJson`, `ToUtf8` and the file-name constants;
- `Format.*`;
- `ComparisonResult`, `MetricComparison`, `SpaceComparison`, `SpaceMatchDiagnostics`, `ProvenanceCompatibility`/`ProvenanceMismatch`, `ReconciliationResult`, `ToleranceProfile` (`Default`, `Resolve`);
- the enums in `Classes/Enums.cs`.

## Decisions
- **net8.0, not netstandard2.0.** It is the existing target, so the move needs no source changes. SAM_UI (`net8.0-windows`) and a future net8.0 MCP host consume it directly.
- **The library keeps the project name and folder; the CLI gets the new project.** This keeps the moved surface minimal and leaves every comparator source file in place.
- **No NuGet package.** Consumers reference `build\` like the other SAM dependencies.
